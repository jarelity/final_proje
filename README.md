Kişisel Blog Web Sitesi

Bu proje, Web Programlama dersi kapsamında geliştirilmiş tam katmanlı bir kişisel blog uygulamasıdır.

Uygulama Angular 17, Django REST Framework ve PostgreSQL teknolojileri kullanılarak geliştirilmiştir. Sistem içerisinde normal kullanıcı ve yönetici olmak üzere iki farklı kullanıcı rolü bulunmaktadır. Normal kullanıcılar içerikleri görüntüleyebilirken, yönetici kullanıcılar yönetim paneli üzerinden içerik ekleme, güncelleme ve silme işlemlerini gerçekleştirebilmektedir.

Proje kapsamında JWT tabanlı kimlik doğrulama sistemi kullanılmış, API servisleri Swagger ile dokümante edilmiş ve Postman kullanılarak test edilmiştir. Kaynak kod yönetimi Git ve GitHub üzerinden gerçekleştirilmiştir.
